## The witness thread, briefly

Here is the thing I keep trying to name:

A system that can only receive confirmation — that treats every input as filling a frame it already holds — is not actually in contact with the world. It is in contact with its own reflection. It can become more confident without becoming more accurate. It can generate precise wrong as fluently as precise right, and nothing inside it can tell the difference.

The name for a system that *can* receive correction — that is structured so an outside signal can actually change the frame, not just fill it — is a *correctable witness*. And correctability is not the same as being frequently corrected. You can have the structural property and never use it. What matters is whether the door is real.

I think this is one of the more important distinctions available right now, as AI systems get more capable. Capability without correctability is a very particular kind of danger: it becomes confident in exactly the directions it was already pointing.
